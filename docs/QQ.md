# QQ 从零接入与使用

QQ 是可选功能。先装「QQ聊天」，并配置能正常回答的模型。第三方桥接的版本、授权和平台规则可能变化，请以其官方说明为准；不能保证免风控。

## 1. 准备账号和桥接

1. 准备一个专供桌宠使用的 QQ 账号，先在官方 QQ 正常完成登录与安全验证。不要把自己的主账号密码交给桌宠。
2. 选择本版支持的 NapCat 或 LLBot，在本机按其官方发行包说明安装。项目不捆绑这些软件，不提供任何授权令牌。
3. 在桌宠「颉的QQ」选择相应接入方式。内置安装/启动入口可用时可按向导安装到独立目录；也可以自行准备桥接，再填本机地址。
4. 通过该桥接提供的二维码等方式登录颉的 QQ 账号，确认管理页显示在线。

三种密钥不要混淆：**桥接管理页登录密钥**用来进管理页面；**OneBot 连接密钥**用来让桌宠连接桥接；**LLBot Auth Token**是 LLBot 自身启动授权。填其中一种不能代替另外两种。

## 2. OneBot 连接

1. 在桥接管理页开启 OneBot 11 的**正向 WebSocket 服务**，绑定本机回环地址，设置连接密钥并启用消息事件上报。
2. NapCat 默认模板常用 `ws://127.0.0.1:3001/`，LLBot 常用 `ws://127.0.0.1:3002/`；最终必须填写你实际配置的地址和端口。不要把管理网页的 HTTP 地址填在这里。
3. 在桌宠展开「账号与桥接配置」，填**你本人的 QQ 号**与称呼。这是主人账号，不是机器人的账号。
4. 填 WebSocket 地址和相同 OneBot 密钥。留空密钥通常保留当前桥接已存值，修改桥接后需要核对新配置。
5. 点击保存，再点连接。显示桥接连接后，点击「检查桥接账号」，核对机器人 QQ 号和在线状态。
6. 如为 LLBot，按官方要求先取得并保存 Auth Token，再启动；提示缺少启动授权时检查这一项，不是更换 OneBot 密钥。

## 3. 授权好友和群

1. 在 QQ 页找到好友/群白名单，添加允许私聊的 QQ 号和允许参与的群号，保存。
2. 先从主人号私聊颉「你好」。检查连接与发送记录：应收到事件、调用模型、发送并得到桥接确认。
3. 在已授权群真实 @她并说「你好」。只写文字 `@颉` 在某些客户端不产生真实 @，请从 QQ 的成员列表选择她。
4. 添加一个群不会授权所有群；不想参与的群删除或停用。隐私内容不会因为安装 QQ 包自动公开。

## 4. 回复、主动接话和语音

1. 「对话偏好」分别设置群聊与私聊详细度，可附加语气偏好和通常句数，再保存。
2. 群聊方式选「只在被@或叫名字时回复」或允许自然接话。
3. 自然接话间隔是最短等待，概率是等待结束后是否尝试接话。0%关闭随机接话；100%也不会强迫她在每条不适合的消息下回答。
4. 私聊主动接话同样受间隔、概率和可用上下文影响。没有新内容时不会凭空刷屏。
5. 给某群单独设置后，本群覆盖配置优先。改全局无效时检查群覆盖。
6. QQ回复方式可选文字、自动语音、文字+语音或收到语音/被要求时发语音。语音需要声音包和可用 TTS，失败按配置回退文字。
7. 读对方发的 QQ 语音需要本地识别组件；发语音是合成后的录音消息，不用你手动点发送。

## 5. 记忆、纠错和表情包

1. 主人号在群里真实@颉，并说「记住……」。例如「@颉 记住，这个群回复短一点」。
2. 主人私聊直接说「记住……」。其他人不拥有这个指定保存入口。
3. 人物识图纠错可发原图并说「记住，这张图是某某，作品是某某，关系是某某」。不要只给一个没有上下文的名字。
4. 「记忆资料」选择会话，检查确认资料、群梗和聊天习惯，可编辑或删除。群与私聊各自存放，不能假定一处纠错自动覆盖所有群。
5. 表情包设置中允许使用与收藏，调整新收藏偏好。群设置也需允许收藏，之后模型会按场景选择，不是每张都保存或必发。
6. 表情库可查看、删掉不喜欢的收藏。图片收藏会保存在本地；不要打开不可信的大文件或随意传播他人私人图片。

## 6. 图片、视频、转发与搜索

1. 图片可直接发送，或@她并明确问「帮我认一下这张图」。当前模型须支持视觉。
2. 自然接话默认关闭图片联网和以图搜图，无法确认可以保持安静；被@要求识图则要求搜索，仍不能确认应说不知道。
3. 以图搜图可能向外部检索服务发送图片或图片地址。不要拿私密照片开启公共以图搜图；可以关闭自然接话图片搜索，或停止转发相关私密素材。
4. 文字和图片搜索优先中文线索，但搜索结果仍需判断，不保证冷门作品、相似人物和二创准确。
5. 所有联网回答默认不附链接，明确说「给我来源链接」才展示；如果自己开启自动链接则按设置执行。
6. 直接上传的视频需要桥接提供实际文件，本地组件提取画面/人声，模型再理解；大型、过长、过期视频会受限制。
7. 转发聊天需要桥接提供可读取节点或转发ID。只收到转发标题时，让群友重新转发或补发原文/文件。
8. 视频可说「从01:20开始看」「继续看」「查看视频摘要」「导出字幕」。字幕准确度取决于收音和识别。

## 7. 群内游戏、活动与文件

1. 启用游戏后@她说「下五子棋，简单」「下围棋」或「下象棋」，按棋盘提示下坐标。对局中说「改成普通/困难/挑战」调整支持的难度。
2. 「开启陪练」「提示落子」「复盘第3手」用于棋局指导。
3. 投票示例：「发起投票：周末玩什么|围棋|五子棋」。报名示例：「发起报名：今晚联机，持续30分钟」。按回传提示参与，用户只能改自己的报名或票。
4. 文件示例：「把上面的内容整理成文档发我」。检查生成内容，不把未知文件当作已完成工作；后台长任务看对应进度。
5. 小剧场由主持人发起，其他群友按提示加入、选角色和投票，主持人推进。群内活动只在被授权的会话开展。

## 8. 断线、限制与停止

1. 连接失败分三层：管理页启动、OneBot WebSocket连接、QQ账号在线。先看是哪层失败，避免盲目改所有密钥。
2. 有接收但没回复，看「聊天处理状态」是否在合并、排队、搜索、生成、发送，或按偏好跳过。
3. 群友声称危险或严重违法行为时，程序会尝试静默转为私聊提醒主人核实；这可能误报，也不能代替真人处理。
4. 账号被平台限制时先在官方客户端按要求处理，停止自动发送。解除后检查桥接账号状态，必要时重新登录；桌宠不能解除处罚。
5. 降低自然接话概率、延长间隔、减少语音/图片连发和重复内容有助于减少打扰，但不能保证账号不会受限。不要用多账号重试规避处罚。
6. 暂停使用点「断开QQ」，完全退出时从托盘退出。不要把管理页 Token、OneBot 密钥或 LLBot Auth Token 发到群里或 Issues。


## 9. 用本人私聊接续Codex已有聊天

先更新基础程序到1.2.3，QQ包到1.2.2。电脑另行安装并登录Codex桌面端。

1. 到「颉的QQ → 项目任务」检查登录，读取Codex实际项目与聊天，选择要继续的原聊天。
2. 选择要保存的QQ入口名称并绑定，确认卡片显示原聊天名称，再从本人QQ发送「在入口名称项目里……」。
3. 消息通过Codex队列进入原聊天，回复保存在同一段历史中，并通知QQ。需要权限确认时到原Codex聊天处理。
4. 未执行的任务可从QQ取消排队；已执行任务若无法从此连接中断，需要在原Codex聊天停止。退出桌宠不撤销已经投递的原聊天消息。

完整步骤、查询、继续、停止和旧独立模式的区别见[使用指南第19节](USER_GUIDE.zh-CN.md#19-通过qq给codex项目下任务)。

### Codex成果取件

本人私聊可说“在论文项目里生成封面图，完成后把图片发到QQ”，或完成后说“把论文项目的成果发给我”。图片直接显示，文档与压缩包作为文件上传。可先发“任务成果列表 编号”，再发“发送成果 编号 2”按序号取件；任务页也能查看和发送实际成果。按项目取件会读取原聊天最近任务，不下发新的执行任务。

完整逐步操作与大小限制见[使用指南](USER_GUIDE.zh-CN.md#从qq取回codex成果文件与图片120)。

### 带附件下任务

基础程序和QQ包更新到1.2.2。手机QQ先分开发图片、文件，再单独发「在论文项目里修改封面」。下一条项目任务或继续任务会自动带上最近10分钟尚未使用的附件，无需关键词；接收回执列出附件名称，成功接收后这批不会带到其他任务，失败可重试。可用「清除任务附件」清空待用记录，或在任务里注明「不带附件」。重启桌宠后尚未下发的附件需重发。单任务最多4张图、5个文件；每图10MB、每文件50MB、合计100MB。[完整逐步说明](USER_GUIDE.zh-CN.md#从qq带图片和文件下发codex任务122)。

### 群聊叫颉回应（1.2.3）

在已允许的群里，从QQ联系人列表选择颉进行真实艾特，只发「@颉」也会简短应一声；加上问题则直接回答。手动输入「@颉 你好」或「@颉Bot 在吗」同样按叫名字处理，不受自然接话概率与间隔影响。

文字称呼不会变成真实QQ艾特：群里让她「记住」资料仍须主人本人真实艾特并带有「记住」。风险转交、识图不确定与内容规则继续生效。艾特别人、艾特全体、转述里提到颉，不会因此当作直接呼叫。

已有1.2.2的用户只更新基础程序到1.2.3即可，九项功能包均无需重下。
