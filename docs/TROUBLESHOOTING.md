# 故障排查

先记下基础版版本、已装包、发生前做的动作和错误原文。基础版与原完整版版本号不同。请勿在反馈中附密钥或完整私人资料。

| 现象 | 按顺序检查 |
| --- | --- |
| 双击没有桌宠 | 是否已全部解压；exe、DLL、resources是否在一起；托盘是否已运行；Ctrl+Alt+J叫回；有无被安全软件隔离。不要下载陌生DLL补齐。 |
| 缺少功能页面 | 功能中心是否显示已安装；安装后是否重启；依赖是否齐全；是否误运行另一份旧目录。 |
| 功能包下载失败 | GitHub访问是否正常；完整包是否下载完成；目录是否刷新成功。可在浏览器下载官方包后离线安装。 |
| 包校验/签名失败 | 文件是否改名、损坏或来自别处；基础版本是否匹配。重新下载官方原包，保留校验，不改哈希。 |
| 安装后没有重启 | 先等安装完成，查看个人目录community-last-result.json；磁盘是否有空余、目录是否可写、聊天/通话是否仍忙。确认无安装进程后再手动启动。 |
| 提示已有文件被修改 | 先备份自己修改的文件；不要盲目覆盖。用新的基础版解压目录重新安装包是更稳妥的恢复方法。 |
| 聊天401/403 | 密钥、登录有效性、所选服务/地区、模型权限。ChatGPT订阅不等于API额度。 |
| 聊天429/额度不足 | 查服务商额度/限额，稍后重试或换自己的可用服务；反复点发送不会补充额度。 |
| 模型没完成回答 | 查看具体错误与模型支持的接口；换一个已验证可用模型；缩短过长上下文；检查网络。 |
| 文字可聊但不能看图 | 模型是否支持图片；连接能力开关是否开启；文件是否过大或失效；PDF与图片能力分开。 |
| 强制联网失败 | 服务和协议是否真正返回搜索工具结果；兼容Chat Completions不一定支持搜索；不能凭开关让文字模型获得联网。 |
| 链接没显示 | 默认隐藏来源；明确要求「给来源链接」，或在QQ设置开启自动来源。 |
| 声音不响 | 声音包已装；启用声音/自动朗读已保存；系统和应用音量；输出设备；先播放预存台词，再测所选TTS。 |
| 预录能放，新话不能 | 预录不依赖TTS，新台词依赖所选系统/在线/本机语音。检查连接、模型和音色，使用试听定位。 |
| 本机TTS无响应 | 独立服务是否运行、端口是否一致、模型是否加载、显卡和内存是否满足。基础版不自带训练好的私人模型。 |
| 麦克风识别不出 | Windows录音机先测试；选对收音设备和中文；桌面麦克风权限；本地模型包完整；看到正在听再说话。 |
| 她说话时听不到我 | 外放模式会暂停收音防回声；先停止她的声音，或换耳机并按当前通话设置操作。 |
| 唤醒不工作 | 语音包/模型已装；唤醒开启；设备可用；没有其他通话占用；调灵敏度。仍失败记录本地唤醒错误。 |
| QQ管理页Network Error | 桥接服务进程是否启动、管理页端口是否正确；管理页Token与OneBot连接密钥是两回事；本机代理是否错误代理回环。 |
| LLBot缺少启动授权 | 保存LLBot官方Auth Token；不要把管理页或OneBot密钥当启动授权。重新启动桥接后看日志，不公开令牌。 |
| 桥接连上但没消息 | QQ账号是否在线、实际机器人号是否一致、是否开启事件上报、白名单是否包含目标、是否用真实@；查看最近收到时间。 |
| QQ收到但不回复 | 处理状态在哪一步；是否跳过/概率未命中/最短间隔；群覆盖设置；模型是否有额度；发送是否被QQ拒绝。 |
| 图片/视频/转发读不到 | 桥接是否返回真实文件或转发节点；文件有无过期；本地组件和视觉模型是否可用。让发送者补发原件。 |
| QQ账号解除限制仍断线 | 官方客户端确认正常；检查桥接账号在线；必要时重新登录并检查OneBot服务。避免频繁重试和重复发送。 |
| 快捷键被占用 | 原完整版或其他软件占用同键；改组合键或清除不用的全局键，保存后重试。 |
| 屏幕黑/原屏幕已断开 | 刷新目标列表重新选择；游戏窗口是否重建或最小化；试窗口区域；受保护画面可能无法采集。 |
| 听歌踩点不准 | 播放器信息和音量检测不是逐拍标注；减少外部杂音，检查当前同步选项。无法保证每首歌精准。 |
| 棋盘无反应 | 是否轮到自己；是否已结束；是否AI思考中；先试新局和简单难度，保留状态截图反馈。 |
| 旧聊天看不到 | 是否切换了服务连接、账号、会话或安装版本；基础版独立目录不会自动读取完整版。 |
| 文件夹很大 | 区分程序、功能包、本地模型、个人缓存、外部QQ和TTS目录；旧版完整备份另计，不要把所有下载目录都算基础版。 |

## 提交有效反馈

1. 从本仓库的 Issues 新建问题。
2. 写明：版本、Windows版本、装了哪些包、使用哪种模型协议/桥接、操作步骤、预期与实际结果。
3. 附去掉账号、姓名、群消息和令牌的错误截图。
4. 功能安装问题可附 `community-last-result.json` 中的错误描述，先检查是否包含自己的本地路径。
5. 不要上传整个AppData、`.enc`、`.env`、登录二维码、麦克风原音或群聊原记录。
