# 数据保存、隐私与备份

## 保存位置

- 程序与已安装功能文件：解压文件夹 `resources/app`。
- 功能安装收据：`resources/app/community-installed.json`，说明这个安装目录有哪些功能。
- **个人资料**：`%APPDATA%\JieDesktopPetCommunity`。包括设置、会话、摘要、记忆、收藏、QQ会话文件和服务配置。
- 原完整版资料目录与基础版独立；基础版不会自动读取原作者 QQ 或训练环境。

「功能中心 → 打开个人资料目录」可打开真实路径。导出备份前停止聊天与通话，等待保存，完全退出再手动复制更稳妥。

## 何时向外发送

| 操作 | 可能发送的内容 |
| --- | --- |
| AI聊天、主动接话、小记 | 当前提问、相关历史、检索到的记忆与角色信息，发往你选择的模型服务 |
| 看图/截图/陪玩 | 你确认共享的图片、区域或选中窗口画面 |
| 在线TTS | 需要朗读的文字及所选音色参数 |
| 本地Whisper/系统语音 | 在本机识别/合成；对话提交后的文字仍会发往当前聊天服务 |
| QQ | 授权会话的消息和必要媒体交给当前模型，生成内容通过本机桥接发送给相应好友/群 |
| 联网和以图搜图 | 搜索词、公开素材图片或图片地址等，取决于检索方式 |
| 天气 | 查询城市及定位参数 |
| 下载功能包 | 访问GitHub Releases下载目录及文件 |

未打开麦克风、屏幕共享或相关检测时，基础版不默认持续监听、共享屏幕或启动QQ。安装包不是同意共享所有个人资料；每个功能按自己的开关与授权范围运行。

## 密钥与跨电脑

聊天API、语音API、桥接等敏感配置使用系统安全存储加密，不显示给模型或写在普通示例里。加密文件也应视为私人资料，**不要提交 `.enc`、`.env`、日志、备份和用户目录**。

Windows用户或电脑更换后，旧加密文件可能无法解密；通过界面重新登录或填写自己的密钥。不要把别人的加密登录配置复制给自己使用。

## 备份步骤

1. 安装「记录与效率」后，在「相伴与扩展」的备份/恢复入口导出。
2. 备份保存到程序目录之外的私人位置，核对生成成功。
3. 未安装该包时，完全退出后复制整个 `%APPDATA%\JieDesktopPetCommunity`。
4. 新电脑先运行一次基础版再退出，按恢复入口导入，或在完全退出状态恢复自己的目录。
5. 重新安装需要的功能包，重新填写无法跨电脑解密的登录配置，确认旧对话和收藏可见。

## 删除与磁盘清理

卸载功能保留个人资料，删除程序目录也不会自动删除AppData。彻底删除资料需要自己退出程序后删除独立目录，此操作会失去历史和密钥。

不要在功能安装期间清理暂存文件。失败的事务备份可能保留用于恢复，先查 `community-last-result.json` 并确认程序已停止。发布包不包括旧版整套备份、QQ运行环境或TTS训练模型。外部TTS安装目录、QQ桥接目录和它们的缓存需要分别统计。


## Codex项目任务与聊天绑定

项目选择器读取Codex本机项目与聊天元数据。绑定后，明确下发的QQ任务通过Codex原聊天队列处理，沿用那段聊天的上下文、模型和权限；内容提交给Codex自己的服务，不使用桌宠普通聊天API。

桌宠只保存QQ入口、目标聊天编号及本条任务的进度和结果。登录凭据由Codex自身管理，不读取或复制其认证文件。绑定和任务记录单独保存在个人资料目录的jie-codex-tasks，当前通用搬家备份不包含这个目录；退出后可单独备份。

退出桌宠不撤销已经进入Codex原聊天队列的消息。未开始的消息可取消排队，已执行内容应到原Codex检查或停止。
