## 1. 下载与第一次启动

1. 打开 [基础版发布页](https://github.com/muwan2006/jie-desktop-pet/releases/tag/v1.1.1)。展开 Assets，选择名字含 `Community-1.1.1-Windows-x64.zip` 的文件。
2. 不要选择 `Source code`，那是提供给开发者的源代码；功能包 ZIP 也不能独立运行。
3. 下载完成后右键压缩包，选择「全部解压缩」。建议解压到自己的应用目录；首次运行和功能包安装需要该目录可写。
4. 进入解压后的文件夹，确认 `Jie.exe`、`resources`、`locales` 和若干 DLL 文件在一起。不要只复制 exe 到桌面。
5. 双击 `Jie.exe`。也可以用 `START-JIE.bat` 启动。此版本没有数字签名；Windows 如给出来源提示，请核对是否从本仓库 Releases 下载以及校验值，不要关闭整个系统的安全防护。
6. 颉出现后右键打开面板。找不到她时查看任务栏右下角托盘，或按默认 `Ctrl+Alt+J` 把她叫回来。
7. 基础版第一次没有聊天账号，也没有安装语音和 QQ。动作、摸头和拖动可以直接体验，AI 对话按第 4 节配置。
8. 想建桌面入口：右键 `Jie.exe` →「显示更多选项」→「发送到」→「桌面快捷方式」。快捷方式只指向原文件，原文件夹需要保留。

本版使用 `%APPDATA%\JieDesktopPetCommunity` 保存资料，与原完整版的目录独立。第一次启动空白对话是正常现象，不会偷偷导入作者或其他安装的资料。

## 2. 认识桌宠和面板

1. 左键触碰头、脸、身体或尾部，可获得不同回应；连着逗她也会变化。
2. 按住桌宠拖动，会显示被拎起衣领的姿势；松开放下。鼠标模拟抓住衣领，画面没有额外的手。
3. 面板「相处 → 桌宠形态」可以切换手持书卷和书案打字两种形态。动作与表情区域可以手动预览已有动作。
4. 「相处」可以递茶、挥手、看书、休息或自由陪伴；「设置」可以修改大小、散步、置顶和速度。调整会保存在本机。
5. 开启「根据聊天和互动使用动作表情」后，聊天句段会配合表情；朗读开启时跟随实际声音。她说话期间鼠标跟随摆头会让位。
6. 左侧导航进入各页。基础版默认只有基本页面；安装功能包后才出现相关项目。「功能中心」始终可用。
7. 关闭面板通常只关闭面板；完整退出请使用托盘或右键菜单「退出桌宠」。

## 3. 安装、卸载可选功能

1. 打开左侧「功能中心」。每张卡片显示用途、版本、下载体积、依赖和当前状态。
2. 查看上方「已安装 X / 9 项」及尚未安装列表。勾选需要的功能，再点「下载并安装所选」；想装齐就点「选择全部未安装功能」。在线安装自动补齐依赖，不必逐个重启。单张卡片也可以单独下载安装。
3. 等待进度结束。下载会检查签名目录、压缩包校验值及解压后文件校验值。校验失败不会作为功能运行。
4. 聊天、通话或办事未结束时先停止任务。校验完后软件自动退出再重启，请不要同时手动打开多个进程。
5. 重启后新页面出现。安装不等于账号已经配置，例如 QQ 还需桥接，语音通话还需选择麦克风。
6. 网络不便时，去 [功能包发布页](https://github.com/muwan2006/jie-desktop-pet/releases/tag/components-v1) 下载所需 `jie-*.zip` 和依赖包。保持原文件名，不要手动解压覆盖程序。
7. 回到「从文件安装功能包」，按住 Ctrl 同时选择主包及依赖包，打开后等待校验和重启。
8. 卸载使用卡片上的「卸载功能」。若有其他包依赖它，先卸载那些功能。卸载保留个人设置及历史，再装仍可继续。
9. 功能中心「刷新功能目录」只刷新下载目录，不会静默安装新功能或清除资料。

如果旧版曾在下载后退出却没安装，先更新到 1.0.1，再点击功能中心的「继续上次安装」。安装程序未确认接手时，程序会保持打开并显示启动记录位置。

基础版 1.1.1 提供原版使用的 28,032 字扩展角色卡，旧的短默认卡会自动升级，自定义卡保留；基本鼠标摆头与书案键盘跟随不需要功能包。语音包 1.0.1 补齐本地唤醒模型。完整对照见 [功能对照表](FEATURE_PARITY.zh-CN.md)。

详细依赖、更新和异常恢复见 [功能包说明](COMPONENTS.md)。

## 4. 接入聊天服务

### 4.1 自己的 API

1. 先在选定服务商处取得 API 基础地址、密钥、可使用的完整模型 ID。网页聊天订阅与 API 权限不一定相同。
2. 打开「聊聊」，展开「聊天连接与模型」及「添加或修改 API 连接」。
3. 选择服务模板；模板只帮你填协议和地址，不提供账号或额度。服务不在模板中时选自定义兼容接口。
4. 填连接名称、基础地址、模型名称及自己的密钥。基础地址通常是 API 根地址，不是网页版聊天网址；不要重复附加 `/chat/completions` 等完整请求路径。
5. 根据模型实际能力选择图片、PDF 或原生搜索。不能看图的文字模型即使勾选图片，也不会因此获得视觉能力。
6. 点击「保存并使用」。刷新模型目录后可从列表选模型；服务没有目录时手填模型 ID。
7. 发一句「你好」，等完整回答。失败先查看界面具体错误，再查 [故障排查](TROUBLESHOOTING.md)。
8. 切换连接从「使用的服务」选择，切换模型在模型栏选择或修改。各连接有独立对话资料；切回原连接可继续。

详细协议、官方文档和语音配置见 [API 配置](API-SERVICES.md)。本项目支持常见接口协议，不能保证每一家服务的私有接口都可用。

### 4.2 ChatGPT 登录入口

1. 「使用的服务」选择「ChatGPT 登录」，按页面登录按钮打开授权页面。
2. 在自己的浏览器内完成登录和授权，返回软件查看连接状态，再选择账户实际提供的模型。
3. 模型目录与可用权限由账号和授权服务决定；看见某个模型名字不代表任何账号都拥有它。
4. 授权不可用、登录失效或目录没有所需模型时，可以重新登录，或使用上面的 API 连接。项目不附带共享账号，也不保证这个入口对所有账号一直可用。

## 5. 聊天、图片与联网

1. 在「聊聊」输入消息，按 Enter 发送；Shift+Enter 换行。中文输入法正在选字时回车优先完成输入。
2. Esc 停止生成或收音；停止后不会自动发送尚未确认的输入。可在设置里自定义这些快捷键。
3. 发送图片使用聊天附件入口，选择图片并确认后提问；例如「这张图片里写了什么」。图片会发送给当前模型，必须选择支持看图的模型。
4. 联网模式按聊天页选项选择自动、禁用或这次必须搜索。必须搜索时若服务不支持或实际搜索失败，会显示原因，不把未搜索内容冒充已核实结论。
5. 网络回答默认隐藏链接。想要依据时明确说「请给来源链接」或「附上链接」。说明文字和实际证据不足的回答应分别判断。
6. 自动识图不能保证认出所有角色和梗图。QQ 自然接话默认只识图；被 @ 要求识图会要求搜索核对，无法确认应说明不知道，详见 QQ 说明。
7. 如要清理某一轮对话或新建会话，在聊天的会话管理中选择相应操作；删除前核对当前服务和会话，避免误删。

## 6. 角色、记忆与会话

1. 打开「角色卡」，查看角色身份和性格；修改后保存，从后续回复开始使用。不要把自己不想外发的秘密写进会发送给模型的角色内容。
2. 「你们的相处约定」可填称呼、安静或活泼的语气、表达习惯与偏好，再点击保存。
3. 「共同经历」查看系统整理的记忆；能编辑或删除的条目按页面按钮操作。错误记忆应及时更正。
4. 对话上下文有容量限制，系统会保存摘要并检索相关旧记录；长期重要内容请明确要求记住并在资料页核对，不保证任何旧消息都能逐字想起。
5. 群聊和好友各自保存，桌宠自己的私密记忆不会自动共享进群。QQ 的主人记忆入口见第 11 节。
6. 安装「游戏与创作」后，互动工坊的记忆检查入口可按来源查看、修改或删除记忆；QQ 纠错保留来源引用，便于核对。
7. 清除会话记忆、清聊天记录和移除 API 连接不是同一操作；看清按钮说明后再执行。资料备份见第 17 节。

## 7. 朗读和预存语音

先安装「声音与朗读」，打开新增的「声音」页。

### 7.1 无密钥的系统语音

1. 声音来源选择「Windows 系统语音」。
2. 点击「刷新系统音色」，选择中文音色。没有中文时先到 Windows 语言/语音设置安装中文语音包，再返回刷新。
3. 勾选「启用声音」，按需勾选「自动朗读 AI 回复」「自动播放预存问候」和日常回应。
4. 设置音量、语速和每次最多朗读字数，点击「保存声音设置」。
5. 在试听台词输入一句话，点击「生成并试听」。系统音色与原角色录音不同，这是正常的。

### 7.2 在线 TTS

1. 来源选择「在线／兼容 TTS API」。
2. 选择模板及接口类型，填服务地址、语音模型、音色名称或 ID、语音密钥。
3. 聊天 API 与语音 API 可以来自不同服务。不要把聊天模型 ID 填成音色，也不要把音色名字填进模型栏。
4. 保存后点击「检查连接」，再「生成并试听」。试听会把台词发给语音服务，可能产生费用。
5. 兼容 Audio Speech 服务需提供本版支持的 WAV；不同服务的权限及格式见 API 说明。

### 7.3 本机 GPT-SoVITS 与预存问候

1. 本机 GPT-SoVITS 是独立大体积引擎，基础版和功能包均不附带作者训练环境或个人模型。
2. 首次使用按「首次安装语音引擎」的独立向导选择目录，下载体积和磁盘要求以向导为准。已有引擎可按向导指定已有位置。
3. 启动本机语音服务并保持其窗口运行，来源选本机，填服务端口、参考录音及对应参考台词，保存后检查连接并试听。
4. 引擎、显卡和模型须兼容；没有可用模型时优先使用系统音色或在线 TTS，不承诺普通 CPU 达到实时速度。
5. 「早安」「欢迎回来」等预存语音直接播放，无需现场合成。「选择日常台词 → 播放预录台词」可逐条试听。
6. 「停止声音」立即停止播放并丢弃迟来的语音结果；本机或在线服务已经开始的计算可能不会立刻停止。

## 8. 麦克风、按键说话和通话

先装「语音输入与通话」，功能中心会补齐声音和本地组件。首次装好后，请到「设置 → 快捷键」确认并保存通话和语音办事的组合键；基础模式不会预占这些语音按键。下文的默认组合键可在这里恢复或自定义。

1. Windows「隐私和安全性 → 麦克风」开启麦克风访问和桌面应用访问。接好设备，确认系统录音机能录到清晰声音。
2. 打开软件语音输入设置，刷新设备并选实际使用的麦克风；不要选立体声混音或不用的摄像头麦克风。
3. 语言选中文；默认本地 Whisper 不要求云识别密钥。首次加载模型比后续识别慢。
4. 按住说话按钮，看到「正在听」再说话，松开结束；勾选「松开后直接发送」可自动提交，低置信度结果可能先放输入框供核对。
5. 想连续聊，使用「接通持续语音」或默认 `Ctrl+Alt+V`。接通后说一句、停顿，识别和回复会自动进行；再按相同快捷键挂断。
6. 外放时她朗读期间暂停收音，避免录入自己的声音，说完恢复。这个模式不是真正同时双向说话；若要避免漏掉打断，先用停止声音快捷键，或改用耳机。
7. 不打开聊天也能语音办事：装电脑办事包后，按 `Ctrl+Alt+Space` 开始，再按一次结束，说「打开 Edge，进入 B 站」等明确请求。
8. 「交给颉 → 叫名字唤醒」可以选唤醒词和灵敏度，再开启。先叫名字，看到「听你说」后说话，也可一句说完。
9. 唤醒在本机检测；朗读、手动收音和持续通话时会暂缓。麦克风质量、环境声与距离会影响成功率，不保证百分百识别。
10. 完成后挂断通话并关闭唤醒，可停止持续监听。语音输入状态在页面可见。

## 9. 屏幕问答与游戏陪玩

需要「屏幕陪伴与电脑办事」和支持看图的模型；朗读及通话另装对应语音包。

1. 「聊聊」点击截图/给她看，框选区域后提问；只有确认选中的画面会用于本轮问答。
2. 连续陪玩展开「一起看屏幕 · 陪玩」，点击「刷新窗口列表」，选择游戏窗口或屏幕。先用小窗口测试效果。
3. 点「开始陪玩」使用预设；也可以改陪伴方式、本机采集间隔、理解间隔、主动程度、最少接话间隔和每小时限额，再点「按当前设置开始」。
4. 查看预览是否为目标内容。目标消失或窗口重建时刷新列表重新选择，不能把黑画面当作模型不理你。
5. 「安静观察」主要记录；陪玩模式会结合画面变化和角色表达主动接话。采集频率不等于模型每秒都能完成理解。
6. 同时接通持续语音，可以直接问「刚才那个线索是什么意思」；语音识别、网络和 TTS 都会增加延迟。
7. 使用「框选要看的区域」缩小范围，减少无关画面。共享前关掉不想外发的聊天、密码或通知。
8. 暂停后可以继续；「停止观察」结束共享并清除临时画面，重新启动软件不会自动共享。这里不采集游戏声音。

## 10. 电脑办事和浏览器

1. 安装电脑办事包，进入「任务与状态」或「交给颉」相关入口。
2. 在「你想让我做什么」输入清楚的任务，例如「用 Edge 打开哔哩哔哩，搜索围棋入门」。点击「交给颉」。
3. 软件直接处理明确的常见网站和已登记入口；其他任务先生成计划，检查目标、步骤和影响后再执行。
4. 浏览器在「浏览器与直接打开」中选择；列表缺少软件时先刷新本机软件，仍没有就到小工具添加 exe 或快捷入口。
5. 网页自动化受网站登录、验证码、控件可访问性及浏览器状态影响。遇到确认或登录时按页面提示手动完成，不会绕过验证。
6. 教过的流程可以按流程名称重用；修改网站页面后可能要重新教。不要把支付、删除或提交个人信息含糊地交给自动流程。
7. 保存或修改文本时先选文件、检查原文和新内容；覆盖前会保留副本。任务列表支持的便签、待办、提醒和专注步骤可按记录撤销。
8. 装语音包后用桌宠旁入口或全局快捷键说任务，识别后自动交给任务系统。是否需要确认由实际步骤决定。

## 11. QQ 群聊和私聊

完整从零接入见 [QQ 操作说明](QQ.md)。基础流程：

1. 安装 QQ 包并重启，配置可用聊天连接。要发语音再安装声音；读 QQ 语音或视频建议安装本地识别组件。
2. 准备给颉使用的独立 QQ 账号，在本机安装并登录 NapCat 或 LLBot，按对应桥接的官方要求配置 OneBot。
3. 在「颉的QQ → 账号与桥接配置」填写**自己的主人 QQ 号**、称呼、桥接地址和连接密钥，再保存。公开版没有预填作者号码。
4. 连接后核对显示的机器人账号；添加允许私聊的好友和允许参与的群。没有授权的目标不会自动参与。
5. 先由主人私聊「你好」，确认收到、生成和发送三段链路，再在一个已授权群 @她测试。
6. 「回复与主动接话」设置群聊参与方式、详细度、自然接话最小间隔、概率和私聊主动间隔。0%不影响直接 @或私聊；100%仍可判断不适合而安静。
7. 「群设置」可以给某群单独设置，保存后只影响该群，避免改全局却被群覆盖规则抵消。
8. 要记住：群里主人**真实 @颉**并带「记住」，如「@颉 记住，这个群叫我暮色」；主人的私聊直接说「记住……」。输入框写出的名字不等于 QQ 的真实 @。
9. 查看记忆资料确认保存内容，纠正或撤销错误条目。其他群友不能用主人入口改你的记忆。
10. 支持图片、短视频和转发聊天读取，但受桥接返回字段、文件可用性、体积与当前模型能力影响。原文件不可用时明确补发，不能只凭「[视频]」文字理解内容。
11. 自然识图默认不以图搜图，未确认可以不接话；被 @要求识图时会搜索核对，仍无法确认就说明不知道。来源默认隐藏，索要链接时才给。
12. 表情包可用内置素材或允许收藏的群友表情。设置收藏、使用频率和偏好；在表情库查看、删除或收藏。未知标记不应原样发给群友。
13. 不合适的话题会静默跳过。群友声称生命危险、伤害他人或严重违法行动时转为私聊提醒主人核实，不在群里不断追问；系统判断可能误报。
14. 群里可发下棋、猜数字、投票、报名或小剧场指令。群对局与桌面棋盘分开，参见后面章节和 QQ 文档。
15. 每天查看「连接与发送记录」和「聊天处理状态」；收不到消息先检查桥接在线及事件上报，生成失败查模型额度，发送失败查账号与桥接，别反复点重连刷消息。

## 12. 五子棋、围棋、象棋与小游戏

五子棋、围棋和象棋需要「游戏与创作」；猜数字、猜拳等桌面道具小游戏还需要「桌面生活与听歌」。QQ 内游戏需要 QQ 包并允许该群游戏。

1. 五子棋：到「交给颉」打开棋盘，选择难度及先后手，新开一局。点击交叉点落子；等待她落子后继续。支持悔棋和认输。
2. 围棋：在游戏入口打开围棋，选择棋盘和难度，依次落子。使用页面的停一手/结束等操作完成对局；页面展示的休闲计分用于陪玩，不作正式比赛裁判。
3. 象棋：进入「互动工坊 → 象棋」，选择简单、普通、困难或挑战，设置执红/执黑并开始。先点自己的棋子，再点可落的目标位置。
4. 等待她思考时不要重复点击新局；可以用悔棋、认输或复盘。难度是本地对弈强度，不是联网专业棋力评级。
5. 对局台词可以开启按真实棋局生成和朗读；关闭后仍能下棋，模型不可用也不影响本地基本落子。
6. QQ 里在已授权群 @她说「下五子棋，简单」「改成困难」「下围棋」或「下象棋」，按回传棋盘和坐标提示落子。用「下在第八行第八列」这类完整坐标更清楚。
7. 「开启陪练」「提示落子」「复盘」「复盘第3手」用于支持的棋局指导。她的建议可能出错，可以自己决定是否采用。
8. 猜数字、猜拳等从对应游戏按钮启动，看提示输入或选择。每局状态独立；只有表情而没有游戏提示时检查页面错误或重开该游戏。

## 13. 互动剧情、表情包和合影

1. 「互动工坊 → 互动剧情」选故事开始，阅读当前一段并点击选项推进。故事进度在当前连接的资料中保存。
2. 自动剧情邀请可开关并设置间隔；不想被打断就关闭，不影响手动继续。
3. 表情包工坊先选已有角色姿态，填写短字幕，选择静态或动画格式，点预览。满意后导出 PNG/GIF；导出到自己选的目录。
4. 合影先选择场景主题或自己的背景，调整角色位置和缩放，填写可选标题，预览后导出。透明背景时确认相应开关。
5. 导出图片默认保存在你选择的位置，软件不会自动公开上传；自己决定是否分享。
6. QQ 小剧场由主持人在授权群发起，群友按提示加入和选角色。主持人推进、投票或结束，过程按群保存；不会替真实群友自动说话。
7. 环境音在游戏/休闲入口选择雨声、风声或翻页声，调整音量，停止按钮结束。它是录好的循环环境音，不会分析现场环境。

## 14. 桌面生活、听歌、青竹和天气

先安装「桌面生活与听歌」。

1. 打开桌面生活设置，分别决定是否允许自动活动、窗口感知和听歌检测；未开启时不自动采集这些信息。
2. 放置桌面摆件后可移动位置，点击或选择相关互动让颉飘过去。窗口太高、坐标变化或屏幕缩放可能影响落点，可重新选择或叫她回来。
3. 青竹在对应入口显示成长状态，按页面操作浇水和照料；颉会在合适时回应，互动和台词不是持续实时模拟。
4. 听歌先用本机播放器播放音乐，开启听歌检测，观察状态是否检测到音量或播放信息。部分播放器不提供曲目信息。
5. 她使用已有完整帧序列摇头晃脑；节奏检测会有误差。可调整当前版本提供的灵敏度和同步设置，不保证每首歌都准确踩点。
6. 听歌感受可开关并调频率；预存短句可直接播放，生成的新感受需要可用模型和所选 TTS。不要把听歌感受当作完整听懂歌词或音轨。
7. 天气先填写城市、查找并确认地区，保存后查看。主动天气提醒可关闭；获取预报会向天气服务发送城市定位参数。
8. 「习惯与收藏」查看成长、收藏和相处状态，按页面操作管理；原有小书斋已移除，不是缺少安装。

## 15. 便签、专注、待办、提醒和项目

先安装「记录与效率」。

1. 「手边的事」新建便签，填标题和内容后保存；完成后可以编辑或删除。
2. 添加待办时填写要做的事，保存后出现在列表；做完勾选完成。需要提醒的事项另设提醒时间。

5. 项目填写名称、进度和下一步，之后更新状态。主动跟进根据已有记录，不代表她在后台真正替你完成项目。
6. 「小工具」可以添加常用网页、软件或文件入口。检查目标路径与别名，保存后可从按钮或明确任务中打开。
7. 剪贴板/选中文字问答使用页面或自设快捷键，先选择文本再触发。只把你愿意交给当前模型的内容发过去。
8. 日常喝水和休息提示在设置中开关并调整间隔；不需要时可单独关闭。

## 16. 小记、回顾、资料和软件通知

1. 「小记」可以开启每天自动一篇，也可以选日期手动补写。自动生成依赖已保存的共同经历和可用模型。
2. 打开条目可查看、修改或删除，保存后以修改后的文字为准。没有发生过的内容应纠正。
3. 「软件与回顾」按入口查看周回顾、资料或软件状态；回顾引用已有记录，不扫描所有电脑活动。
4. 添加可用的本地资料时按页面选文件或目录，确认是否允许发给模型。文件更新后按入口刷新资料索引。
5. 外部任务通知默认不开启。需要时开启「接收外部任务状态提醒」，先点「测试完成提醒」验证桌宠能显示。
6. Codex 接入可用「导出 Codex hooks 示例」检查生成配置，再按客户端支持方式接入。支持 hooks 的客户端需在新会话的 `/hooks` 检查并信任；不是所有客户端都支持同一事件。
7. 其他软件可按界面示例向指定任务事件目录写入小型状态 JSON；状态包括 working、waiting、done、failed、canceled，同一任务使用同一 id。
8. 忙碌、通话或勿扰期间提示可能延后；旧通知仅留列表。只想看结果可在列表查询。

## 17. 角色包、插件与资料搬家

1. 「相伴与扩展」查看当前角色包。导入前检查来源和包说明，选择包并预览后启用。
2. 角色包只改变其提供的角色信息或资源；AI 模型和 API 权限仍由聊天连接决定。
3. 插件/工具连接只配置自己信任的服务，检查它请求的权限及实际动作；可随时禁用或移除。
4. 搬家前先在备份入口导出个人资料，保存到安装目录之外；再完全退出桌宠。

6. 没装效率包时，可完全退出后手动备份 `%APPDATA%\JieDesktopPetCommunity`。这是个人资料，不要放入公开仓库或发给陌生人。
7. 卸载一个功能包保留资料。想删除全部个人数据时，先退出程序，再删除独立资料目录；这个操作无法通过重新安装恢复。

## 18. 快捷键、更新、退出与问题反馈

1. 「设置 → 快捷键」点击某项按键按钮，按新的组合键，最后「保存快捷键」。占用提示说明有其他程序或桌宠实例使用该按键。
2. 常用默认键：叫回 `Ctrl+Alt+J`，聊天 `Ctrl+Alt+C`，切换形态 `Ctrl+Alt+F`，停止声音和回复 `Ctrl+Alt+X`；语音包安装后可配置通话和语音办事。
3. 未安装功能的快捷键不应使用；功能包卸载后相关入口禁用。安装包后到设置确认并保存需要的按键。
4. 基础版更新先备份资料，再从托盘退出所有基础版进程，下载新版本到新目录。首次启动确认资料和聊天连接正常后再处理旧程序文件夹。
5. 不要把新基础版直接盖在满是旧功能文件的目录里。新目录需要重新安装对应版本的功能包；个人资料仍在独立 AppData 目录。
6. 功能包更新使用功能中心，依赖和基础版兼容性不满足时先更新基础版。软件不会未经操作自动替你安装。
7. 普通关闭面板不会完全退出。安装或备份前使用「退出桌宠」，不要反复结束不明进程。
8. 报错先看 [故障排查](TROUBLESHOOTING.md)。反馈时提供版本、Windows 版本、已安装功能、复现步骤和脱敏截图，**不要提交令牌、聊天原件、账号加密文件或包含隐私的屏幕录像**。


## 网易云音乐与外放语音

1. 打开网易云音乐，先播放一首歌，再打开桌宠「软件与回顾 → 音乐与音量」。
2. 「控制对象」默认自动优先网易云，也可固定选择网易云；要调整 Windows 总音量则选择系统。
3. 点击上一首／下一首或设置音量。结果会区分实际确认和仅发送请求；不会再向所有窗口广播切歌消息。
4. 语音可说“换首歌”“网易云下一首”“声音小一点”“音量调到百分之二十”，也可通过语音办事入口使用。
5. 在「声音」页刷新收音设备。自动选择在只有一个 WASAPI USB 麦克风时优先使用它；也可手动指定设备，所有语音入口使用相同规则。
6. 外放时保留“外放收音时自动压低网易云音乐”。录音期间压低网易云的应用音量，录完即恢复；通话结束、取消或识别进程退出也会恢复。在压低期间手动改过音量，会保留手动设置。系统总音量和颉的声音不受影响。
7. 网易云未提供 Windows 媒体会话时，上一首／下一首先尝试定向窗口控制。播放／暂停可用媒体键按钮；无法确认状态时会明确提示。若提示未响应，请检查网易云的全局快捷键或系统媒体控制设置。多个播放器同时打开时，优先固定控制对象。

自动压低音乐用于减轻歌词混入麦克风，不是完整的声学回声消除；音乐很响或麦克风离扬声器过近时仍可能识别错误。


## 图片能力与搜索能力分开设置

1. 在“聊聊 → 连接与陪玩 → 聊天连接与模型 → 添加或修改 API 连接”中，编辑自己已经保存的连接。
2. 所用模型支持图片时，展开“模型能力与高级设置”，勾选“模型支持图片”，点击“保存并使用”。这个开关只允许发送图片，不会给纯文字模型增加视觉能力。
3. 能看图不等于支持模型原生搜索。没有原生搜索的视觉接口也能描述画面、读取文字；不必为了发图片勾选不受支持的搜索功能。
4. 需要核对人物身份或出处时，程序会尝试已有的独立中文检索和以图搜图；没有有效证据就说明无法确认，不能把相似外形当成身份结论。
5. QQ 群聊默认自然接话仍不搜索图片；被明确 @ 要求识图时仍须核对实际以图搜图结果，无法确认时回答不知道。链接继续默认隐藏。
6. 如果自己将本轮联网模式设成“这次必须联网搜索”，仍须取得真实检索结果；没有结果时会提示重试，不会伪装成功。


## 象棋难度升级与原收藏表情包

1. 已有基础版先退出程序，用 1.1.1 修复包更新原来的 Jie.exe；再到功能中心刷新目录，更新「游戏与创作」到1.0.1、「QQ聊天」到1.2.0。其他包、语音模型无需重新下载。
2. 到「互动工坊 → 中国象棋」选择难度。简单对应旧困难，普通对应旧挑战；新困难加入更深推演、连续吃子和将军应对，挑战进一步加深搜索。
3. 每步思考时间上限依次约 0.65、1.1、3、6.5 秒，具体能达到的搜索深度取决于局面和电脑速度；已经找到必胜将杀时可提前落子。这是本地对弈强度，并非专业等级或胜率保证。
4. QQ 和桌宠窗口共用同一套难度与时限。群里 @她说「象棋难度切换到挑战」或直接说「困难」即可；仅当前棋手能调整正在进行的棋局。后台想棋不会阻塞桌宠窗口，断开或取消时不会补发过时落子。
5. 旧棋局首次读取时，原困难自动改为简单、原挑战改为普通；旧简单和普通合并到新的简单。棋盘、先后手、对局和悔棋记录保留，迁移只执行一次。
6. QQ 收藏表情按颉的 QQ 账号与原群聊或私聊识别，切换聊天模型或 API 后仍能读取原收藏；不同 QQ、群与私聊分别保存，不跨会话混用。在「颉的QQ → 表情媒体」选择会话可预览或删除。


## 19. 通过QQ给Codex项目下任务

### 连接已有项目与聊天（推荐）

1. 将基础程序升级到1.2.0，在功能中心更新「QQ聊天」到1.2.0。电脑另行安装并登录Codex桌面端；安装包不包含Codex账号或额度。
2. 按第11节连接颉的独立QQ账号，确认「你的QQ号」填写本人用于私聊的账号。
3. 打开「颉的QQ → 项目任务」，点击「检查Codex登录」，开启「允许你的QQ私聊下发Codex任务」。
4. 在「连接已有Codex项目与聊天」中点击「读取Codex项目与聊天」。这里读取的是Codex本机实际项目与聊天，不会创建项目或新聊天。侧栏里未归类的聊天也能选。
5. 「Codex项目」可选具体项目、未归类聊天或全部；「已有聊天」选择要接续的那段聊天。同名项目会同时显示目录，按实际目录区分。列表较多时可按标题查找，或点击「读取更多聊天」。
6. 「保存到QQ入口」选择已有入口，例如「桌宠」，可保留它的名称和别名；也可选择「新建QQ入口」并填写名称，例如「论文」。点击「绑定所选聊天」。卡片显示「原Codex聊天：……」表示已经绑定。
7. 每条消息原文投递，不追加目录提示。同名项目按实际目录区分。如果原聊天的旧默认目录已失效，需要先在Codex修正目录，或将旧目录设置为指向当前项目的系统目录连接；不可用时会明确报错，不假装投递成功。绑定原聊天后，各聊天分别投递并跟踪进度；同一聊天的消息依次进入它自己的队列，一个项目执行较久不会阻止其他项目同步。
8. 从本人QQ私聊发「项目列表」，可看到Codex实际项目、近期未归类聊天，以及已经启用的QQ入口。只有已绑定或登记的QQ入口能接收执行任务；未绑定的项目请先按以上步骤选择具体聊天。

### 下发、查看与接着做

1. 发送「在桌宠项目里检查构建问题，完成后告诉我结果」，或「交给Codex：桌宠：修复刚才讨论的设置问题」。使用上一步设置的QQ入口名称或别名。
2. 收到任务编号表示桌宠已接收。消息通过Codex桌面自己的队列进入所绑定的原聊天，沿用那段聊天的上下文、模型和权限设置；不会另开一段独立聊天。
3. 到Codex桌面打开原聊天，可以看到提交的任务与实际回复。原聊天忙碌时先排队，桌宠不会启动另一个实例抢占该聊天或强行打断正在处理的内容。
4. 发「任务进度 a1b2c3d4」查看该编号的实际状态；「任务列表」查看最近项目任务。结果只匹配这条QQ消息对应的执行轮次，不把其他人在桌面提交的任务当成你的QQ任务结果。
5. 完成后收到实际结果摘要；发「任务结果文件 a1b2c3d4」可获取Markdown记录，包含可读取的实际结果、文件和命令退出状态。失败或未执行的检查不当成通过。
6. 发「继续任务 a1b2c3d4：接着修复剩余问题」，继续该任务原来的Codex聊天，获得新任务编号；重新绑定QQ入口不会把旧任务的追问悄悄移到另一段聊天。
7. 普通聊天仍使用桌宠所选API。项目任务使用Codex自己的账号和额度，切换桌宠聊天API不会更换项目聊天。

### 确认、取消和断线

1. 绑定原聊天的任务由Codex桌面执行。涉及权限确认或需要回答的问题时，在原Codex聊天中处理；桌宠不会替原聊天批准操作或改写它原有的权限设置。
2. 发「停止任务 a1b2c3d4」。消息尚未执行时，从原聊天队列删除本条消息，其他排队内容不受影响。
3. 已接手的任务会尝试请求中断。如果当前连接无法中断桌面拥有的任务，会明确提示到原Codex聊天点击停止，并继续查询实际结果；不会把没有停止的任务显示成已停止。已产生的文件修改不会自动撤回。
4. 电脑、Codex桌面与桌宠需要保持可用，QQ桥接需在线才能回传消息。QQ临时离线时保留待通知结果，发送未获确认时不重复刷屏，可主动查询。
5. 消息一旦进入原Codex队列，退出或断开桌宠不会自动撤销它。重新打开桌宠后只恢复结果查询，不重新投递同一条消息。需要撤销时，在退出前取消排队或到原Codex聊天处理。
6. 未能确认是否投递成功时，不自动重发；先检查原聊天，再决定是否另发任务。关闭QQ任务入口也不保证停止已经交给Codex执行的内容。
7. 群聊、他人私聊、转发和附件内容不能直接下发开发任务。项目/聊天绑定在本机由你选择；更换电脑后重新检查Codex登录、实际目录和聊天是否仍然可用。

### 从QQ带图片和文件下发Codex任务（1.2.2）

1. 先更新基础程序到1.2.2，再在功能中心刷新目录，将「QQ聊天」更新到1.2.2。原完整版使用1.33.2。电脑上先打开并登录Codex，绑定好项目与已有聊天，开启远程任务。桌宠、QQ桥接和Codex需保持运行。
