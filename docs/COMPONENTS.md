# 功能包安装、离线使用与更新

## 在线安装

1. 运行解压后的基础版，打开「功能中心」。确保整个程序目录可写，磁盘空间足够。
2. 看清卡片用途、体积和依赖，点击「下载并安装」。在线包来自本仓库 `components-v1` Release，不通过聊天模型生成下载地址。
3. 等进度结束，暂停当前聊天、通话或办事。软件校验通过后自动退出并重启完成安装。
4. 重启后在左侧找到新增页面，按 [完整指南](USER_GUIDE.zh-CN.md) 配置账号、设备或服务。

首次安装语音输入需要三个包：语音输入、声音与朗读、本地识别组件。首次安装 QQ 或游戏创作需要角色表情素材。共享包只装一份。

## 离线安装

1. 在能联网的电脑打开 [功能包发布页](https://github.com/muwan2006/jie-desktop-pet/releases/tag/components-v1)。
2. 下载需要的 `jie-功能名-版本.zip` 及上面提到的依赖，保留原文件名。不要选基础版 ZIP 或 GitHub 自动生成的 Source code。
3. 复制到目标电脑，在功能中心点「从文件安装功能包」。Ctrl 多选所需包，点打开。
4. 软件使用内置签名目录校验；文件改名、缺依赖、下载不完整或版本不匹配时会拒绝安装并显示原因。
5. 等待校验、退出和重启。不要手工往 `resources/app` 覆盖解压文件，这会绕过收据并导致无法正常管理。

## 卸载和修复

1. 在功能卡片点击卸载，确认后重启。若被其他包依赖，先卸载依赖它的功能。
2. 卸载只移除该包登记的程序/资源，个人对话和设置保留。再安装可继续使用。
3. 文件丢失时使用「重新安装／修复」。已有文件被手工修改时，安装器可能为保护修改而拒绝覆盖；备份修改后恢复原版文件或使用新基础目录。
4. 安装失败会尽量恢复先前文件，结果保存于个人资料目录 `community-last-result.json`。保留的失败事务用于排查，不要在事务进行中删除文件。
5. 下载校验失败不会安装；重新下载完整包。不要为了安装改哈希或关闭校验。

## 更新边界

「刷新功能目录」只接受与当前基础版兼容且签名正确的目录。基础版本不同需要先更新基础版。首发版不提供基础程序的后台自动替换。

基础版放在新目录升级时，功能收据跟随旧安装目录，因此新目录需要重新安装功能包；AppData 内的个人资料可继续用。保留旧目录便于回退，确认无误后再删旧目录，不要无限保留整套旧版本。

## 开发与信任

功能目录用 Ed25519 签名，应用固定公开验证密钥；ZIP 和每个解压文件均检查 SHA-256。路径遍历、链接、额外文件及覆盖基础程序的包会被拒绝。签名密钥不在仓库和下载包内。

共用后端保留在基础版，功能页面、专属资源和大型本地组件按包提供。功能包是本项目的可信扩展代码，不是任意网络插件的沙盒；不要从聊天消息随意安装他人伪装的包。
