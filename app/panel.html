聊天连接与模型
添加或修改 API 连接

选择服务模板，填写自己的地址、密钥和模型。每个连接分别保存连续聊天，重开会恢复选择。API 的费用由对应服务收取。

模型能力与高级设置

按服务及模型实际支持的能力选择。图片用于附件和屏幕陪玩；不能看图的模型无法陪玩。搜索只接入 Responses、Claude 和 Gemini 的原生搜索工具。

地址填写到 API 根路径，不包含 /chat/completions 等具体接口，也不把密钥写入地址。密钥输入框留空可保留同一服务已存的密钥；换服务地址时需重新填写。在线服务使用 HTTPS，本机可以用 HTTP。

还未连接

重开会恢复上次连接和模型。API 模型可手动填写或刷新目录；ChatGPT 登录显示账号向桌宠开放的模型，可能与网页不同。连续对话保存在本机。

正在使用 ChatGPT 套餐

查询最新信息时可选择“必须联网”；联网回复默认隐藏链接，明确说“给我来源链接”时会提供。

一起看屏幕 · 陪玩

选择游戏窗口或区域，点击“开始陪玩”。她会结合前后画面主动推理、吐槽并配合表情和声音；你提问或按住说话时优先回应你。突发变化会保留关键帧，网络理解和语音生成仍需要时间，无法保证抓住一闪而过的画面。这里不采集游戏声音。

陪玩每1秒采集，按小时限额均匀安排理解，新“开始陪玩”预设每小时最多600次；持续语音停顿约0.75秒自动提交，沉默不会挂断。外放时她朗读期间暂停收音，说完自动继续。你开口时优先回应，画面理解在后台进行。自动理解使用当前服务的额度或 API 费用，声音沿用“自动朗读AI回复”设置。安静观察仍至少隔30秒理解一次。停止后清除临时画面，重开不会自动共享。
