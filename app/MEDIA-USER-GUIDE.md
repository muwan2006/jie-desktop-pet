# QQ 图片与视频使用说明

适用于原完整版 1.36.0。入口：颉的QQ → 表情媒体 → 图片与视频。

## 一、先检查模型连接

1. 在“聊聊”页连接你平时使用的聊天模型。
2. 展开“找图、视频与视觉连接设置”。
3. 如果聊天模型本身支持图片，“看图使用的连接”可以选“跟随当前聊天连接”。
4. 如果聊天模型只支持文字，先在聊聊页添加另一个真正支持图片的 API 连接，填写模型并启用该连接的图片能力，保存。返回此页，在“看图使用的连接”中选择这个连接；也可以选已登录的 ChatGPT。
5. 点“保存图片与视频设置”。切换视觉连接不会切换你原来的文字聊天连接。

图片核对和视频画面观察使用视觉连接；视频的角色回答及纯文字追问继续使用当前聊天模型。勾选能力不会让实际不支持图片的模型自动拥有视觉能力。

## 二、添加本地图库

1. 展开“添加或修改本地图库”。
2. 填写名称，点“选择文件夹”选择自己准备的图片文件夹。支持 PNG、JPG/JPEG、GIF、WebP、BMP，单张不超过10MB。
3. 选择是否包含子文件夹。
4. 在“允许哪些会话使用”中选择主人私聊或需要开放的群聊，可以多选。没有选中的会话不能通过 QQ 取用这个图库。QQ 未连接时可以先连上，再设置会话范围。
5. 点“保存并更新图库索引”。全部图库合计最多5000张，最多30个图库。图片原件保存在原目录，软件保存索引和描述。
6. 点“查看图片与描述”，可预览、编辑描述和标签。例如补充“明日方舟终末地、颉、橙色眼睛”。
7. 需要自动描述时，可逐张点“生成描述（调用视觉接口）”，或点“批量生成描述（调用视觉接口）”。这会发送缩略图给所选视觉服务，可能产生正常API费用；不会在添加文件夹后自动执行。每次批量处理最多40张尚未描述的图片，完成后可再次点击继续处理。

轻量索引结合文件名、文件夹名、图片描述与标签查找，再实际查看候选图。随机文件名的图片建议先生成描述。身份不确定时可手工补充标签，不应仅凭外观相似确认人物。

修改路径：在对应图库点“修改路径与使用范围”，改路径后保存；旧路径索引会移除并扫描新目录。往原文件夹增删图片后可点“更新索引”，QQ找图前也会刷新相应图库。

添加图片：点“添加图片”，选择文件后复制进这个图库，不移动原文件。移除图库或从索引隐藏图片不会删除源文件。

## 三、通过 QQ 找图、发图

私聊直接发送，群聊先 @她。例如：

- 发一张黄昏竹林的图片
- 给我发一张望和颉的合照
- 换一张
- 给我图片出处
- 保存这张图片到图库

先找本会话可用的本地图库，没有确认符合描述的候选时，再尝试中文主题的联网图片搜索。下载候选并查看画面后，才会发送实际图片；无法确认时会明确说明。表情包和图库分开管理，不会把普通照片自动收藏成表情包。

默认内置图片搜索，服务要求验证时可能暂时不可用。也可在设置中填写自己的 SearXNG `/search` 地址（需开启 JSON 和图片类别）。留空恢复内置搜索；无需把聊天API密钥填在这里。仅管理员通过桌宠界面修改配置。

默认不附网络出处链接，可单独索取；既有“显示来源”设置开启时也会显示实际来源。“保存到图库”仅主人操作，保存到本会话已开放的第一个启用图库；可以在文件夹中进一步整理。

找图有正常视觉识别和搜索误差，不能保证每次都找到；不要把未确认的近似图当成准确身份结果。

## 四、通过 QQ 看视频链接

支持 B站和抖音的完整视频链接、常见短链接、QQ分享卡片；B站也可直接发BV号。抖音复制分享文案中带链接即可。

1. 私聊发送链接，或在群聊 @她并附链接。
2. 她会回一个媒体任务编号，后台获取视频、抽帧和读取字幕/对白。期间可以继续普通聊天。
3. 内容读取后，由当前会话角色卡生成回答。默认不贴一串来源链接。
4. 可以继续问“视频最后那个镜头是什么意思”“刚才她为什么这么说”。笔记按原会话保存，重启后可继续讨论已经读到的文字记录。
5. 长视频可说“继续看”或“从02:10开始看”；进度使用原视频时间。

每次默认读取最多5分钟，可改成2、5、8分钟。每次最多抽8帧观察画面，并分段处理人声；超过所设时长时会说明范围，可继续读取后续。字幕/人声和画面采样都有局限，不能据此声称逐帧看过，也不能保证不漏掉一闪而过的内容。只取得标题封面不算看过视频内容。

目前单次下载视频及音轨合计上限64MB，默认尽量选择较低画质便于分析。过长或体积过大的视频可改发较短片段。视频原件、音轨及临时Cookie在处理完毕后清理，聊天保留笔记。

## 五、平台提示需要登录怎么办

普通公开内容先尝试直接读取。抖音可能要求有效Cookie；B站字幕等内容也可能需要登录态。

1. 用你自己的浏览器正常登录对应平台，并确认能打开这个视频。
2. 使用你信任的Cookie导出工具，导出该平台的Netscape格式 `cookies.txt`。不要将这个文件发到QQ群或公开仓库。
3. 在本页展开“平台登录资料”，点“导入B站Cookie”或“导入抖音Cookie”，选择对应文件。
4. 软件只保留对应平台域名的Cookie，在本机加密保存。重新发链接尝试。
5. 不需要时点“清除对应平台Cookie”。失效时重新导出、导入。

导入Cookie并不保证所有链接都能读取。私密/删除视频、会员或地区限制、验证码、接口变化和网络问题会单独导致失败；不会尝试绕过平台的访问限制。此次开发实测B站公开视频的画面和中文人声读取成功；抖音无登录态测试返回需Cookie，未将其记作已完成认证后的实测。

## 六、进度、取消和存储

- QQ可说“媒体任务进度”“取消媒体任务”“停止看视频”；默认操作自己的最近任务，主人也可管理当前会话任务。
- 桌宠本页“媒体任务与缓存”显示最近任务、进度、失败原因和取消按钮。
- 撤回原始任务消息、断开QQ或退出程序会停止未完成任务，重启后不会自动重复发送。
- 每次最多6项媒体任务排队，逐项执行，不把下载/转写塞进普通聊天队列。
- 图片缓存默认最多200MB，并自动清理过期内容；可调整或手动清理。图库原件不计入可清理缓存，不会随清理删除。
- 图库描述任务可以在本页停止，已完成的描述保留。

个人资料主要位于用户数据目录的 `qq-media-library.json` 和 `jie-qq-media`，与程序文件分开。更新程序不会覆盖已有图库设置和观看记录。
