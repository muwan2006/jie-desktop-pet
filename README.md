# 颉桌宠 · 基础版

一卷书，一程相伴。一个可互动、可聊天，并按需添加语音、QQ、游戏和屏幕陪伴的 Windows 桌宠。

本项目在 Codex 的帮助下开发。公开基础版从完整版 1.31.0 整理而来，单独编号为 **1.1.0**，使用独立个人资料目录。它不会读取原作者的账号、聊天记录或语音训练资料。

**[下载基础版](https://github.com/muwan2006/jie-desktop-pet/releases/tag/v1.1.0)** · **[完整使用说明](docs/USER_GUIDE.zh-CN.md)** · **[功能包下载](https://github.com/muwan2006/jie-desktop-pet/releases/tag/components-v1)** · **[反馈问题](https://github.com/muwan2006/jie-desktop-pet/issues)**

## 第一次使用

1. 打开上方「下载基础版」，在 Assets 中下载 `Jie-Desktop-Pet-Community-1.1.0-Windows-x64.zip`。`Source code` 是源码，不是可直接运行的软件。
2. 用 Windows「全部解压缩」，放到自己有写入权限的文件夹，例如 `D:\Apps\JieCommunity`。不要在压缩包里启动，也不要只拖出一个 exe。
3. 双击解压后的 `Jie.exe`，出现颉后右键打开面板，进入「聊聊」。想先体验动作，可直接摸头、拖动、递茶或切换形态。
4. 展开「聊天连接与模型」，配置自己的聊天服务。没有连接也能使用基础桌宠动作；AI 对话需要可用的账号或 API。
5. 想加功能时打开左侧「功能中心」，勾选所需功能后点击「下载并安装所选」，也可「选择全部未安装功能」。依赖会一同下载；全部校验后只重启一次，新增入口随即出现。
6. 从「功能中心 → 完整使用说明」或本仓库文档继续操作。解压目录的 `使用说明.md` 和 `docs` 文件夹也保留离线说明。

## 基础版与功能包

基础版保留两种形态、拖动与身体互动、鼠标摆头、书案键盘跟随、动作表情、文字聊天、28,032 字完整角色卡、共同经历、设置和快捷键。共用后端随基础版提供，功能页面、扩展素材和大型运行组件按需安装。

| 可选包 | 用途 | 自动安装的依赖 |
| --- | --- | --- |
| 声音与朗读 | Windows 系统音色、在线 TTS、本机 TTS、预存问候 | 无 |
| 语音输入与通话 | 麦克风输入、按键说话、持续通话、叫名字唤醒 | 声音、本地识别组件 |
| 本地识别与文档组件 | Whisper 模型、Python、音视频与文档读取组件 | 无 |
| QQ聊天 | 连接自己的独立 QQ 账号、群聊和私聊、会话记忆、本人私聊下发Codex项目任务 | 角色表情素材 |
| 游戏与创作 | 五子棋、围棋、象棋、互动剧情、表情包、合影、环境音 | 角色表情素材 |
| 角色表情素材 | QQ 和创作共用的静态表情及动画 | 无 |
| 桌面生活与听歌 | 摆件、道具小游戏、青竹、听歌互动、天气、习惯与收藏 | 无 |
| 屏幕陪伴与电脑办事 | 屏幕问答、陪玩、网页与电脑事务 | 无；语音入口另装语音包 |
| 记录与效率 | 小记、项目、便签、待办提醒、软件通知、角色包与备份 | 无 |

QQ 桥接软件、聊天模型服务和本机 GPT-SoVITS 引擎不包含在基础版内，须按说明单独配置。功能包不会附带任何人的付费账号或密钥。大型本地组件的准确下载体积显示在功能中心。

## 能力范围

- Windows x64 便携版；目前不提供 macOS、Linux 或手机安装包。
- 聊天适配 Responses、Chat Completions、Claude Messages 和 Gemini generateContent。具体模型、看图、联网、文件能力取决于所选服务；接口兼容不等于所有模型都支持全部能力。
- 动画为预制逐帧素材；语音识别、屏幕理解、棋局 AI 和联网检索可能出错。陪玩需要采集、模型生成及语音合成时间，不承诺真人通话般的延迟。
- QQ 接入依赖第三方桥接及平台允许的账号状态，不能保证免于平台限制。软件提供连接检查、退避与发送节制，不能解除 QQ 账号处罚。
- 象棋提供休闲对弈、难度、悔棋与复盘；当前重复局面规则不覆盖正式比赛的全部长捉判例。
